# Gusdorf Cardiology

Free clinical cardiology education by Jason Gusdorf, MD.

## Sections

- Clinical cardiology curriculum
- 696-tracing ECG library and quiz
- 265 narrated heart-sound recordings
- Current ACC/AHA and ESC guideline directory

AI-related cardiology research remains at [LLMs for Doctors](https://llmsfordoctors.com/trials?tag=cardiology).

## Development

```sh
npm install
npm run dev
```

Production builds are deployed to the `gh-pages` branch.

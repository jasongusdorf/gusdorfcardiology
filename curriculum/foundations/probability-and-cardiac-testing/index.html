Probability before testing

Choose tests by the question they can answer and the decision threshold they can cross.

Mechanism

A test result changes probability according to its likelihood ratio and the pretest probability. Testing helps most in the intermediate zone: low probability invites false positives, while very high probability may justify treatment or definitive testing without an intermediate screen.

Build intuition first

Three layers of understanding

Start simple, add a mental model, then prove you understand it by teaching the mechanism back without jargon.

5

Explain it like I’m five

A test does not announce truth; it updates a starting guess. The same positive result means more when disease was already plausible.

↔

A mental model that sticks

A smoke alarm means something different in a kitchen and a fireworks factory because the starting chance of fire differs.

The analogy is a scaffold—not a substitute for the physiology.

Feynman technique

Teach it back

Choose a test and explain pretest probability, how each result changes it, and exactly which decision crosses a threshold.

Your explanation is complete only if it can answer:

  • 1. State the target diagnosis first.
  • 2. Separate sensitivity from predictive value.
  • 3. Know when more testing cannot help.

Deep dive

A reusable reasoning framework

Move from physiology to pattern recognition, diagnostic proof, and an action that changes the patient’s trajectory.

1

Build the mechanism

A test result changes probability according to its likelihood ratio and the pretest probability. Testing helps most in the intermediate zone: low probability invites false positives, while very high probability may justify treatment or definitive testing without an intermediate screen.

2

Recognize the pattern

Build the pretest estimate from symptoms, tempo, risk, examination, ECG, and prior studies. Separate “Is disease present?” from “Is it causing this presentation?” and “Will defining it change management?”

→
3

Confirm and classify

State the target diagnosis and the action threshold before ordering. Use serial measurements when trajectory carries more information than a single value.

→
4

Act and reassess

Stop when additional testing cannot plausibly change treatment. Escalate when a dangerous diagnosis remains above the acceptable miss threshold.

By the end, you should be able to

  • 01Explain the underlying mechanism without relying on a memorized label.
  • 02Recognize the highest-yield clinical and physiologic findings.
  • 03Choose a test because of the decision it can change.
  • 04Start appropriate management and name what must be reassessed.

Check your understanding

  1. Mechanism: What variable changes first, and what changes downstream?
  2. Discrimination: Which finding best separates this process from its closest mimic?
  3. Testing: What result would actually change what you do next?
  4. Safety: Which common shortcut creates the greatest risk? Hint: Treating a positive stress test as synonymous with obstructive coronary disease.
